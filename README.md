Particle Reveal 

A premium React component that reveals images through animated dots, creating a modern and engaging visual effect for creative websites and digital experiences.

✨ Features

- Animated dot reveal effect
- Smooth image transitions
- Responsive and lightweight
- Easy customization
- Built with React, TypeScript, and Vite

📦 Tech Stack

- React
- TypeScript
- Vite

🚀 Getting Started

Install dependencies

npm install

Start the development server

npm run dev

Build for production

npm run build

🎨 Use Cases

- Agency websites
- Portfolio projects
- Landing pages
- Interactive galleries
